# Harness

Internal Node CLI for the mixshift-amazon-ppc plugin. **Not user-facing** — invoked by Claude via the Bash tool during skill execution.

See [`docs/productization/HARNESS-REWRITE.md`](../../../docs/productization/HARNESS-REWRITE.md) for the architecture sketch and milestone plan.

## Quick start (development)

```bash
cd plugins/mixshift-amazon-ppc/harness
npm install
npm run build         # bundles src/cli.ts → dist/cli.js
node dist/cli.js --help
```

## Layout

```
harness/
  package.json
  tsconfig.json
  scripts/build.mjs       # esbuild bundling script
  src/
    cli.ts                # entry point + command registry
    commands/             # one file per top-level command group
    lib/                  # shared modules (auth, context, sql, render, …)
  dist/                   # bundled output (committed; runtime invokes this)
  tests/                  # vitest unit tests + snapshots + evals
```

## Why we commit `dist/`

The plugin runtime invokes `dist/cli.js` directly. End users should not have to run `npm install` to use the plugin. We ship the bundled JS so plugin installs stay simple.

The bundle is regenerated by CI on every commit that touches `src/` or `scripts/build.mjs` — see the workflow in `.github/workflows/`.

## How Claude invokes it

From a `SKILL.md`:

```bash
node {{PLUGIN_ROOT}}/harness/dist/cli.js prefetch \
  --brand <brand-slug> \
  --skill <skill-id> \
  --date 2026-05-13 \
  --json
```

The `{{PLUGIN_ROOT}}` substitution is the surface-specific plugin install path. Claude resolves it before running the command.

## Exit codes

| Code | Meaning |
|---|---|
| 0 | Success |
| 1 | Real error (failed validation, DB connection lost, etc.) |
| 2 | Command exists but is not yet implemented (stub) |

This lets Claude distinguish "skill is broken" from "feature isn't built yet."

## Surface detection

The harness reads `CLAUDE_SURFACE` env var to determine where it's running. Valid values: `claude_code`, `cowork`, `chat`. Falls back to heuristics (env-var presence, FS shape) when not set explicitly.

Affects: default output adapter, `ui` command availability, telemetry tagging.
