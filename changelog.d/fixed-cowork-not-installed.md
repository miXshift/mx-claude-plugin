- **Claude in Cowork no longer tells you MixShift is not installed when it is.** In Cowork the `mixshift` command is never on PATH and each new conversation starts signed out, and Claude could read either one as a missing plugin, CLI or connector. It now looks for the plugin's CLI to the end before saying it cannot find it, treats "No credentials found" as a sign-in and sends you the sign-in link, and no longer points Cowork users at the remote connector. The FAQ has a new entry for this; the quick fix is to say "sign in to MixShift".
