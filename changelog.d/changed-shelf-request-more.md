- **Shelf data is on for every organization, and you can ask for more.** The
  Amazon Shelf skill no longer needs MixShift to switch it on per organization:
  every organization starts on a monthly discovery allowance. When the month's
  allowance is used up, the answer now says how to ask for more, and the skill
  offers to send that request to MixShift for you ("request more shelf
  requests"); MixShift raises it for the current month.
