- **Check a DSP order before you switch it on, in one step.** `mixshift dsp readiness` runs the whole pre-launch checklist on an order: media type, goal, tracked products, real targeting on every line item and an approved creative on each, and lists what to confirm in the DSP console (an off-Amazon conversion, Amazon's automatic responsive ad). Each line passes or fails with the ids it checked and how to fix it, so an order that Amazon would refuse to start is caught before you try. It only reads.
- **"Amazon O&O and Publisher Direct only" in one step.** `mixshift dsp supply-preset` finds the third-party exchange supply Amazon adds to new DSP line items, keeps Amazon-owned inventory and Publisher Direct, and previews removing the rest. Nothing changes until you confirm, and every removed target is kept in the change record so it can be added back.
