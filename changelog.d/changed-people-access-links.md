- **Setup codes are now minted at People & access.** The service setup skill,
  the `mixshift auth service-setup` help and error text, and the auth docs now
  send you to People & access (https://build.mixshift.ai/people) to create a
  service credential and get a setup code, which works with Google sign-in. If
  your organization is on a legacy single sign-in tenant that has not moved to
  OAuth yet, you can still use mcp.mixshift.io/admin for now. If a setup code
  comes back unknown, expired, or already used, mint a fresh one and retry right
  away.
