- **`mixshift doctor` now catches a broken `mixshift` link.** If a `mixshift` link on your PATH (for example in `~/.local/bin`) points at a plugin folder that was moved or removed, doctor names the link, says where it pointed, and prints the command to remove it. It also notes a link that still works but runs an older plugin copy. The plugin does not create that link itself; doctor only reports it and never deletes anything.
