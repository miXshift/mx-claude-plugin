- **You are asked once which brand a DSP advertiser belongs to.** After DSP campaigns are built or changed, or whenever you work on one advertiser, the plugin checks whether a brand already claims it. If none does, it asks which of your brands it belongs to, shows you the exact change, and writes it only after you confirm, so those DSP changes show on the right brand's change log from then on. Nothing is guessed or filled in for you, an advertiser a different brand already claims is never reassigned, and scheduled runs never ask or write; they just list the advertisers still unassigned. Brand setup asks the same question for a brand that runs DSP. New commands for the same job: `mixshift context dsp-advertiser show` and `assign`. This needs the MixShift service update that adds the lookup; until then the plugin says so and changes nothing.
