- **`mixshift cli locate` and `mixshift doctor` now show every installed copy of the plugin.** A machine keeps each version the plugin host ever installed, so the first `cli.js` a search finds can be an old one. `mixshift cli locate` prints the path of the newest copy, `mixshift cli locate --list` shows every copy with its version, and `mixshift doctor` has a new `CLI copies` section that says when this session is running an older copy than the newest installed one. `mixshift --version` (or `-V`) prints just the running version.
