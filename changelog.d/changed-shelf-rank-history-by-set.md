- **Rank history reads your running tracking sets, and one set when you name it.** A rank-history read now covers the ASINs of your running tracking sets by default, so an ASIN that only a paused set lists no longer shows up in it. A paused set's history is still there: name the set with the new `--set` option (`mixshift shelf rank-history "<keyword>" --zip <zip> --set <set id>`), or name the ASIN with `--asin`. `--set` reads the ASINs one set lists, running or paused, and `mixshift shelf tracking list` shows the set ids. Each answer now also says which tracking sets it read, and marks the paused ones. Ask Claude for the rank history of one set and it passes the set for you.
