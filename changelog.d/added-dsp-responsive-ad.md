- **Build a responsive ecommerce ad on DSP from the plugin.** Amazon's automatic responsive ad can only be
  switched on in the DSP console when an order is created. You can now build a responsive ecommerce ad for
  your products from the plugin instead, preview it, create it paused and attach it to a line item, where it
  goes through Amazon's review like any creative. A DSP ad cannot be deleted, so the plugin always shows you
  the exact ad first.
