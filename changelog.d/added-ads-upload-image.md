- **Claude can add a new logo or custom image to your Creative Asset Library from a link.** Give Claude an https link to a PNG or JPEG and the name it should have, for example "Using MixShift, add this logo to the Creative Asset Library for <brand>: <link>, named <name>." Claude downloads and checks the image first and shows you its type, size and dimensions and any asset that already has a similar name; nothing reaches Amazon until you say yes. An image added this way is shared with everyone on that ad account and cannot be removed from MixShift, so add only images you want to keep there. Video still goes in through the Amazon Ads console.
