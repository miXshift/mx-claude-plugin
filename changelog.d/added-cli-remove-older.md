- **`mixshift cli remove-older` puts older plugin copies out of use, only when you ask.** A machine keeps every version the plugin host ever installed, so a scheduled task or saved prompt can keep running months-old code. Run `mixshift cli remove-older` to preview which older copies would be moved (it changes nothing), then add `--yes` to move them into a `.trash` folder. Nothing is deleted, the copy you are running and the newest copy never move, and each moved copy comes with the command to put it back. The plugin never does this on its own, on update or otherwise. `mixshift doctor` and the update guide now point to it when older copies exist.
