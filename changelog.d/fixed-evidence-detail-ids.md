- **Evidence item lists keep the same reference across wording updates.** In the
  monthly report with intelligence, a finding's long item list (for example the
  list of campaign changes behind a "what changed on campaigns" finding) is
  served as its own block. Its reference used to be built from the finding's
  wording, so a reworded finding broke any citation to the list. The reference
  now follows the finding itself, so a brief that cites it stays valid when the
  service updates its wording.
